# Livrables

Ce dossier contient tout ce que Claude produit pour Prijanth. Les documents fournis par Prijanth vont dans `context/import/`, pas ici.

## Organisation

| Dossier | Contenu |
|---------|---------|
| `site-web/` | Sites internet, landing pages, maquettes HTML/CSS |
| `application/` | Outils, scripts, automatisations |
| `tiktok/` | Briefs vidéo, scripts, hooks, calendrier éditorial |
| `revision/` | Fiches de révision sur les outils et technologies |

## Convention de nommage

Format : `AAAA-MM-JJ_nom-court-descriptif`

Exemples :
- `2026-05-22_landing-page-portfolio`
- `2026-05-22_script-tiktok-dataiku-intro`
- `2026-05-22_fiche-revision-aws-ml`

**Règle d'or :** ce qui entre ici vient de Claude. Ce qui vient de l'extérieur (PDF, export Notion, capture d'écran) va dans `context/import/`.
