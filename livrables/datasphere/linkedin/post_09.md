# Comment passer AWS Cloud Practitioner en 3 semaines
**Format :** Liste plan semaine par semaine
**Objectif :** Éduquer / Générer du trafic
**Hashtags :** #AWS #Certification #Cloud #CloudPractitioner #Data Universe

---

AWS Cloud Practitioner est souvent sous-estimée.

Pourtant, c'est la porte d'entrée vers tout l'écosystème AWS. Et elle se prépare sérieusement en 3 semaines.

Voici comment. 🗓️

---

**Semaine 1 — Comprendre les fondamentaux**

Objectif : comprendre le cloud et les grands principes AWS.

- Les modèles cloud : IaaS, PaaS, SaaS
- Les régions et zones de disponibilité AWS
- Les services core : EC2, S3, RDS, Lambda, VPC
- Le modèle de responsabilité partagée

Ressource principale : cours gratuit AWS Skill Builder "Cloud Practitioner Essentials" (6h).

---

**Semaine 2 — Les domaines clés de l'examen**

Objectif : couvrir les 4 domaines du CLF-C02.

- Facturation et gestion des coûts (16 % de l'examen)
- Sécurité et conformité (25 %)
- Services cloud AWS (33 %)
- Architecture cloud (26 %)

Ressource : cours Stephane Maarek sur Udemy (souvent à 13 € en promo).

---

**Semaine 3 — Entraînement intensif**

Objectif : valider avec des examens blancs.

- 2 examens blancs par jour minimum
- Analyser chaque mauvaise réponse, comprendre pourquoi
- Réviser les points faibles identifiés

Score cible sur les examens blancs : 85 %+ avant de se présenter.
Score de passage à l'examen : 70 %.

---

**Le jour J**

Durée : 90 minutes, 65 questions.
Format : QCM et réponses multiples.
Coût : 100 USD (souvent remboursé par l'employeur).

---

Avec cette méthode, le taux de réussite au premier passage est très élevé.
